# ServerCraft Frontend

React-based frontend for ServerCraft Windows Edition.

## Development

```bash
# Install dependencies
yarn install

# Start development server
yarn start

# Build for production
yarn build
```

## Tech Stack

- React 18
- Tailwind CSS
- Font Awesome
- Axios

## Structure

```
src/
├── App.js          # Main application component
├── App.css         # Styles
├── components/ui/  # Shadcn UI components
└── index.js        # Entry point
```
